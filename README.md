## Sobre o projeto

Projeto de análise de vendas, custos e lucratividade desenvolvido no Power BI, com o objetivo de transformar dados em informações visuais para apoiar a tomada de decisões.

## Análises realizadas

- Valor de venda por modo de envio — Gráfico de Cascata
- Custo médio de envio por mercado — Treemap
- Valor médio de venda x meta de 350 — KPI
- Lucro médio por categoria de produto
- Evolução da margem de lucro ao longo do tempo

## Principais indicadores

- Valor de venda
- Custo de envio
- Lucro
- Margem de lucro
- Valor médio de venda
- Meta de vendas

## Competências

- Análise de dados
- Criação de KPIs e dashboards
- Visualização de dados

## Ferramentas

- Power BI
- Git e GitHub
- CSV

## Base de dados

O projeto utiliza os seguintes conjuntos de dados:

- Clientes
- Pedidos
- Produtos
- Vendas

## Objetivo

Analisar o desempenho das vendas, custos e lucratividade da empresa, identificando tendências, resultados e oportunidades de melhoria por meio de indicadores e visualizações de dados.
